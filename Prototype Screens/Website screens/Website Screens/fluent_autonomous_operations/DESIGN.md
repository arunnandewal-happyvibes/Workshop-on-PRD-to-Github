## Brand & Style

This design system delivers an enterprise-grade operating environment for autonomous Copilot agents, orchestrations, and mission-critical workflows. Designed for information workers, systems administrators, and enterprise operators, the aesthetic synthesizes Microsoft Fluent 2 principles with deep system transparency. It prioritizes psychological safety, predictability, and verifiable execution over synthetic spectacle.

### Aesthetic Persona
- **Atmosphere:** Controlled, calm, analytical, and authoritative. Clean multi-tier slate-white surfaces ground complex multi-agent execution graphs into digestible operational layers.
- **Visual Stance:** Corporate Modern infused with Fluent materials—combining high-density structured data matrices, luminous subtle gradient state rings, precise hairpins, and measured micro-elevations.
- **Agentic Signals:** Autonomous activity is never disguised. The interface visually demarcates machine intent, live execution streams, automated edits, and manual human-in-the-loop checkpoints through deliberate color anchoring and telemetry badges.

## Colors

The color palette establishes an authentic enterprise productivity environment centered around Microsoft Fluent 2 chromatic logic, supplemented by distinct autonomous workload tokens.

### Surface and Structure Tiers
- **Canvas Base (`#F3F4F6`):** The persistent app boundary layer behind panels, canvases, and split views.
- **Secondary Shell (`#F8F9FA`):** Navigation rails, contextual toolbars, and timeline tracks.
- **Card and Active Surface (`#FFFFFF`):** High-priority focus areas, work canvas panes, modal sheets, and operational nodes.
- **Dividers & Borders (`#EDEBE9` and `#E1DFDD`):** 1px structural grid definition ensuring content boundaries remain razor-sharp without heavy visual noise.

### Agentic Brand Accents
- **Fluent Communication Blue (`#0F6CBD`):** Primary interactions, affirmative execution flows, and key system controls.
- **Copilot Intelligence Gradient (`#106EBE` to `#6366F1`):** Reserved exclusively for generative agent creation, autonomous reasoning triggers, and synthesized insight containers.
- **Teams Violet (`#6264A7` / `#5B5FC7`):** Multi-agent orchestration sessions, cross-tenant handoffs, and team channel sync states.

### Semantic State System
- **Running / Active:** Light soft-blue tint surface (`#EFF6FC`) with `#0F6CBD` text and a continuous 1.5px radiant ring.
- **Requires Approval:** Cautionary amber tint surface (`#FFF9E5`) paired with `#B45309` text and high-contrast border framing.
- **Completed:** Subdued sage background (`#F1FAF0`) bound to `#107C41`.
- **Failed / Stalled:** Critical tint (`#FDF3F2`) bound to `#D13438`.
- **Paused / Dormant:** Neutral tint (`#F3F2F1`) bound to `#605E5C`.

### Connected Microsoft 365 Fabric Badges
Dedicated micro-brand anchors identify autonomous connector endpoints:
- **Excel:** `#107C41`
- **PowerPoint:** `#C43E1C`
- **Word:** `#185ABD`
- **Teams:** `#6264A7`
- **Outlook:** `#0078D4`
- **SharePoint:** `#038387`

## Typography

Typography prioritizes high-density legibility, technical precision, and cognitive clarity across dense multi-agent telemetry views. 

### Font Selection & Characteristics
- **Primary Typeface (`Segoe UI`, system-ui):** Standardized across all interface hierarchies to ensure native parity with desktop productivity operating systems. Clean geometry, generous counters, and distinct glyphs guarantee effortless scanning.
- **Monospace Telemetry (`JetBrains Mono`):** Applied to agent invocation parameters, deterministic schema nodes, token usage counters, and step payload dumps.

### Typographic Rules
- **Tabular Figures:** All numeric displays (latency, token costs, completion percentages, run steps) must enforce OpenType tabular figures (`font-variant-numeric: tabular-nums`) to prevent layout shifting during real-time streams.
- **Hierarchy Separation:** Section titles leverage semibold weights (`600`) at modest scales rather than overly large display sizes, maintaining desktop density.
- **Text Truncation:** Sub-agent reasoning logs and output previews must employ mid-string or strict two-line clamping with monospace tooltips on hover.

## Layout & Spacing

The layout is built upon an 8px architectural grid with a 4px sub-grid for micro-alignments (chips, badges, and icon buttons).

### Layout Geometry
- **Master-Detail Workspace:** Structured around a persistent 3-tier layout:
  1. **Primary Global Rail (48px or 64px width):** Fast switching between agent topologies, triggers, and enterprise logs.
  2. **Orchestration / Canvas Zone (fluid flexible column):** Visual flow of execution nodes, sub-agent hierarchies, and data pipelines.
  3. **Copilot Inspector / Context Drawer (360px to 440px fixed width):** Real-time chain-of-thought, payload schema, human approvals, and connector status.
- **Adaptive Breakpoints:**
  - **Desktop (>= 1200px):** 12-column layout; gutter `1.5rem`, outer margin `2rem`. Three-pane layout fully expanded.
  - **Compact Desktop / Tablet Landscape (768px - 1199px):** Inspector drawer transforms into an overlay slide-out; gutter `1rem`, outer margin `1.5rem`.
  - **Mobile (< 768px):** Single-column stacked mode. Execution graphs switch to a linear timeline stack with bottom-sheet modals for approval gates.

### Component Spacing Rhythm
- **Internal Card Padding:** Compact telemetry cards use `space-md` (12px); primary capability cards and approval sheets use `space-xl` (24px).
- **Element Clusters:** Related meta-elements (badges, app icons, time deltas) sit `space-xs` (4px) to `space-sm` (8px) apart.

## Elevation & Depth

Visual depth is achieved through delicate tonal boundaries paired with calibrated Fluent micro-elevations. The system uses subtle light diffusion rather than heavy dark drop shadows to maintain enterprise composure.

### Elevation Levels
- **Base (Elevation 0):** Flat surfaces (`#FFFFFF` or `#F8F9FA`) bound by a 1px solid border (`#EDEBE9`). Used for idle cards, execution node shells, and passive data cells.
- **Resting Focus (Elevation 4):** `0px 1.6px 3.6px 0px rgba(0, 0, 0, 0.04), 0px 0.3px 0.9px 0px rgba(0, 0, 0, 0.02)`. Applied to active agent cards, elevated action panels, and interactive controls on hover.
- **Interactive Floating (Elevation 8):** `0px 3.2px 7.2px 0px rgba(0, 0, 0, 0.06), 0px 0.6px 1.8px 0px rgba(0, 0, 0, 0.04)`. Used for dropdown menus, capability pickers, floating command bars, and sticky telemetry status pills.
- **Modal Interruption (Elevation 16 / 32):** `0px 6.4px 14.4px 0px rgba(0, 0, 0, 0.08), 0px 1.2px 3.6px 0px rgba(0, 0, 0, 0.05)`. Applied to modal approval sheets, escalation gates, and permission delegation panels.

### Copilot Luminous Edge
When an agent is actively computing, reasoning, or executing tool use, the host card transitions from a standard shadow to a 1px composite outline with a faint ambient glow:
- Border: `1px solid rgba(99, 102, 241, 0.35)`
- Shadow: `0px 0px 12px 0px rgba(16, 110, 190, 0.08)`

## Shapes

The design system maintains strict geometric rigor tailored for professional tools. Rounded corners balance software precision with modern approachable ergonomics.

### Corner Radius Mapping
- **Buttons, Text Inputs, and Small Chips (`rounded-md`, 6px):** Delivers a crisp, tactile target that visually nests inside parent surfaces.
- **Standard Enterprise Cards (`rounded-lg`, 8px to 10px):** Used for individual capability items, node checkpoints, and timeline log wrappers.
- **Major Surfaces and Modal Sheets (`rounded-xl`, 12px):** Applied to large approval sheets, popover dialogs, and workspace panels.
- **Pills (`rounded-full`, 9999px):** Strictly reserved for dynamic execution status badges (e.g., "Running", "Requires Approval") and connected M365 application tags.

## Components

### Buttons
- **Primary:** Solid `#0F6CBD` background, `#FFFFFF` text, 6px border radius, 32px height (compact enterprise default) or 36px (prominent). Subtle `#115EA3` background on hover.
- **Secondary / Standard:** `#FFFFFF` background, `#242424` text, 1px border `#D1D1D1`. Hover: `#F5F5F5` background, `#D1D1D1` border.
- **Copilot Action:** Linear gradient (`#106EBE` to `#6264A7`), `#FFFFFF` text, paired with a white sparkle glyph. Used exclusively for initiating multi-step autonomous processes.
- **Danger / Abort:** White surface with `#D13438` border and text; turns `#D13438` solid with white text on critical human override.

### Status Badges
Pill-shaped containers (`height: 24px`, padding `0 10px`, font size `11px`, font weight `600`) communicating deterministic system states:
- **Running:** Light blue background (`#EFF6FC`), `#0F6CBD` text, containing a pulsating 6px dot.
- **Completed:** Neutral sage background (`#F1FAF0`), `#107C41` text, paired with an affirmative check mark.
- **Requires Approval:** Vibrant soft amber (`#FFF9E5`), `#B45309` text, 1px amber border, paired with an alert shield icon.
- **Failed:** Rose background (`#FDF3F2`), `#D13438` text.
- **Paused:** Neutral gray (`#F3F2F1`), `#605E5C` text.

### Connected M365 Application Badges
Compact metadata pills used inside agent execution sequences:
- Displays official micro-brand icon (14px) alongside app moniker ("Excel", "Outlook", "Teams", "SharePoint").
- Neutral border `#E1DFDD`, background `#FFFFFF`, with the app's signature accent color applied to the icon and subtle left indicator bar.

### Agent Capability Cards
- Structural cards (`rounded: 10px`, border `1px solid #EDEBE9`, background `#FFFFFF`, padding `16px`).
- Header displays agent name, parent orchestrator, and real-time state badge.
- Body holds capability summary, consumed tokens, and authorized connector icons.
- Footer contains dynamic action buttons ("Inspect Run", "Revoke Access", "Modify Prompt Scope").

### Execution Timeline Nodes
Vertical stepped visualization representing live execution pipelines:
- **Node Dot:** 16px circular marker centered on a 2px vertical connective track (`#EDEBE9`).
  - Active nodes feature an outer animated ring pulsing between `#0F6CBD` and `#6366F1`.
  - Passed nodes switch to solid `#107C41` checkmarks.
  - Pending nodes remain hollow `#C8C6C4`.
- **Content Block:** Right-aligned adjacent container with title, duration counter (in tabular monospace), and collapsable tool-call payloads.

### Modal Approval Sheets
High-stakes human-in-the-loop validation dialog:
- Centers with an Elevation 16 shadow and dark translucent overlay (`rgba(0, 0, 0, 0.4)`).
- Header highlights the agent identity, requested permission level, and expiration countdown.
- Body provides a structured "Diff View" (e.g., "Proposed changes to 'FY25_Budget.xlsx'").
- Dual primary action buttons: "Approve Execution" (affirms action) versus "Reject & Terminate" (quarantines agent).

### Progress Bars
- 4px height track in `#F3F2F1` with an 8px radius.
- Standard deterministic progress uses `#0F6CBD`.
- Generative reasoning steps use an animated streaming gradient (`#106EBE` transitioning to `#6366F1`).
